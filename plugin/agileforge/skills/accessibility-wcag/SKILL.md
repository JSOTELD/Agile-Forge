# Accesibilidad WCAG 2.1 AA

> **Especialidad:** `accessibility-wcag` | **Categoría:** design | **Nivel:** Principal | **Estado:** ACTIVE

Habilidad técnica especializada dentro del catálogo del ecosistema AgileForge.

## Cumplimiento de Accesibilidad WCAG 2.1 AAA
1. **Ratio de Contraste**: Exceder ratio de 14:1 en modo oscuro entre el texto base y el fondo (#f8fafc sobre #070a12).
2. **Navegación por Teclado**: Todo botón, selector o enlace debe ser alcanzable mediante Tab y operable con Enter o Espacio.
3. **Lectores de Pantalla**: Proveer etiquetas aria-label y atributos semánticos para tecnología asistiva.
