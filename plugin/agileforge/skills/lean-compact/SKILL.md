# Lean Execution & Compact Code

> **Especialidad:** `lean-compact` | **Categoría:** agile | **Nivel:** Principal | **Estado:** ACTIVE

Habilidad técnica especializada dentro del catálogo del ecosistema AgileForge.

## Principios Lean y Código Compacto
1. **YAGNI (You Aren't Gonna Need It)**: Evitar abstracciones especulativas, clases intermedias innecesarias o frameworks sobredimensionados.
2. **Densidad y Claridad**: Priorizar código directo, legible y conciso frente a patrones hiper-complejos sin valor inmediato.
3. **Entrega Continua**: Minimizar el tiempo de ciclo entre la toma de la historia y el envío a revisión con evidencia verificable.

## Criterio de Verificación
- Todo entregable generado con esta skill debe satisfacer la Definition of Done (DoD).
- La evidencia debe registrarse mediante la herramienta MCP `submit_for_review`.
