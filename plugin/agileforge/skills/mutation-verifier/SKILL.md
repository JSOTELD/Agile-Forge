# Mutation Testing Verifier

> **Especialidad:** `mutation-verifier` | **Categoría:** qa | **Nivel:** Principal | **Estado:** ACTIVE

Habilidad técnica especializada dentro del catálogo del ecosistema AgileForge.

## Verificación de Pruebas por Mutación
1. **Resistencia de Tests**: Modificar condiciones booleanas y operadores matemáticos para comprobar que la suite de pruebas falla de forma inmediata.
2. **Validación de Rollback**: Verificar que ante una excepción no controlada dentro de una transacción, los datos en SQLite no queden corruptos.

## Criterio de Verificación
- Todo entregable generado con esta skill debe satisfacer la Definition of Done (DoD).
- La evidencia debe registrarse mediante la herramienta MCP `submit_for_review`.
