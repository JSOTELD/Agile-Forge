# UI/UX Pro Max

> **Especialidad:** `ui-ux-pro-max` | **Categoría:** design | **Nivel:** Principal | **Estado:** ACTIVE

Habilidad técnica especializada dentro del catálogo del ecosistema AgileForge.

## Estándar Profesional de Interfaz de Usuario
1. **Mobile-First Real**: Asegurar que cada vista y modal sea operable cómodamente con una sola mano en pantallas móviles.
2. **Tap Targets**: Superficies interactivas mínimas de 44x44px conforme a lineamientos de usabilidad humana.
3. **Feedback Visual Inmediato**: Todo botón o acción destructiva debe contar con estado de hover, foco visible (:focus-visible) y notificación toast reactiva.
