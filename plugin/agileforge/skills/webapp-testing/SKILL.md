# Automated Testing Suite

> **Especialidad:** `webapp-testing` | **Categoría:** qa | **Nivel:** Principal | **Estado:** ACTIVE

Habilidad técnica especializada dentro del catálogo del ecosistema AgileForge.

## Suite Automatizada de Pruebas Unitarias
1. **Aislamiento Total**: Cada test unitario debe ejecutarse de forma independiente sin depender del estado previo de la base de datos.
2. **Cobertura de Casos Borde**: Probar inputs malformados, arrays vacíos, strings con caracteres especiales e intentos de path traversal.

## Criterio de Verificación
- Todo entregable generado con esta skill debe satisfacer la Definition of Done (DoD).
- La evidencia debe registrarse mediante la herramienta MCP `submit_for_review`.
